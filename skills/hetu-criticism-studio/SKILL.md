# 文学评论

先经河图稳定CLI/MCP发现当前安装包、capabilities及本包方法；携带精确WorkRef、management_ref和活动摘要，不新建Codex插件或假定当前作品。

先读已有专业工程、固定来源和意见。读取固定原作和二手材料 → 准确引文 → 提出解释和理由 → 比较不同读法 → 准备评论段落与主张锚点 → 固定意见返工 → 复核依据 → 评论与完整论证本。作者给出自然语言目标时由Agent准备结构，不要求作者在GUI重复填表；业务不依赖运行窗口。

引文固定来源修订及UTF-8字节区间，只追加不可覆盖；原作与二手评论分别标记。每个解释保留适用范围、引文和推理理由。关系区分支持、质疑和限定，允许多种解释共存，不把图可达性、支持数量或循环当逻辑真理。文章主张固定段落摘要、准确选区和所用解释组合摘要；段落、相关解释或关系变化后待复核，旧锚点绝不定位到新稿。新建或主动调整锚点必须匹配当前原文和依据；已有过期记录可保留历史。局部备选固定整个段落摘要，应用后旧主张与意见过期，其他段落字节保持。

方法与完整反例见[工作流程](references/workflows.md)，动作参数见[操作地图](references/operations.md)。保存后回读固定修订与原操作；未知先get_operation，CAS冲突保留原输入，不换键重发。阶段边界用create_handoff保存固定依据、未读范围和下一步。

专业检查不代替文学判断。外发、费用、正文采纳和定稿沿作者确切决定执行；不得扩大作品范围或绕过宿主事务。
